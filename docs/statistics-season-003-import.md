# Temporada 03 — 2007–2008

Origem: Google Drive Bolão/Temporada 2007-2008. Autorização do usuário para importar e commitar na main em 2026-11-11; confirmou que o período é a Temporada 3.

Dados: 13 jogadores, 13 temporadas regulares, 7 consolidados de playoffs, 18 fases de playoffs, 75 fontes com SHA-256, 38 revisões. Imagens originais permanecem privadas no Drive. Os registros anteriores season-001 e season-002 não são alterados. Os prints da pasta Extras não são importados.

A indicação Conference Semifinals é registrada como quarterfinals. Jogadores sem registro de playoffs não recebem estatísticas zeradas. Para Dias, os prints oferecem agregado dos playoffs sem separação de rodada; nenhuma rodada é inferida. As médias e percentuais são preservados com a precisão exibida no jogo.

Verificação estática antes da publicação: integridade referencial das fontes e correspondência de contagens, médias de minutos/pontos e percentuais diretamente verificáveis. A execução de npm run stats:validate, testes e build deve ser conferida no ambiente Node do projeto.
